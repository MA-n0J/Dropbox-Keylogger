# Dropbox-Keylogger
  A keylogger which i created to try to log keystrokes and send it to dropbox and some other stuffs which lets you see the most repeated words which is logged, The logger adds itself to startup so test it in a virtual environment

 # Note
   1. I havent yet made it stealthy enough to hide from Antivirus but the best this could do so far is escape windows defender, so if you really need this to be used consider adding your own contributions, i am still learning, so i will definitely keep this project updated.

# Steps to run this 
   1. install the libraries.
   2. First create an dropbox api, its free for developers and testing :).  
   3.  Add the Dropbox API in the code.
   4.  Convert this python file into a exe file using the pyinstaller library for running in windows.
   5.  Run the exe file, it will add itself to the startup and captures the keystrokes and sents it over dropbox and annoys you lol.
